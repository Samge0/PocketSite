站点包格式说明

PocketSite 可导入的标准静态站点 ZIP 包
1
一个合法的 .zip 文件

标准的 ZIP 压缩包，无需重命名，直接选择即可导入。

2
包内必须有 index.html

它是站点的入口页面，位于「有效根目录」。缺失时站点标记为 无 index，打开会 404。

3
纯静态内容

HTML / CSS / JS / 图片 / 字体 / 音视频均可；不支持 PHP、Node 等服务端程序。

✓ 推荐结构：index 在 ZIP 根部

site.zip
├── index.html      必需 · 入口
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/
    └── logo.png

✓ 也支持：外面多包一层文件夹

site.zip
└── mysite/          自动识别并提升
    ├── index.html
    ├── css/
    └── images/
导入时会自动检测：若 ZIP 内只有一个文件夹且其中有 index.html，会把该文件夹内容提升为站点根目录，无需手动解压调整。macOS 压缩产生的 __MACOSX、._* 垃圾文件也会自动忽略。

✗ 常见错误示例

site.zip
├── page1.html      缺 index.html
├── page2.html
└── css/
问题：两个平级页面没有 index.html，且不在同一子文件夹内，无法自动提升。修复：把入口页面重命名为 index.html 后重新打包。

打包小技巧

💡
选中「内容」打包，而不是「外层文件夹」

Windows：进入文件夹 → 全选（Ctrl+A）→ 右键压缩。
macOS：选中内容 → 右键「压缩」。两种都会得到入口在根部的标准包。

💡
路径建议用英文

HTML 内引用相对路径（./css/style.css）最稳妥；资源文件名避免空格与中文，防止部分设备解码异常。

💡
相对路径引用资源

站点通过 http://127.0.0.1:端口/ 直接伺服 ZIP 根目录，index.html 里写 ./xxx 或 xxx/yyy 的相对引用即可正常加载。
