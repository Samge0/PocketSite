PocketSite 是手机端的静态站点管理器：内嵌纯 Kotlin 手写的 HTTP 服务器，每个站点独立端口、独立开关、可同时运行。应用内 WebView 预览断网可用 —— 无需 Termux、无需 root、零运行时依赖，飞行模式照常工作。

Why PocketSite

在手机上跑个静态页，
为什么要这么难？

PocketSite 把「装环境、敲命令、切目录」全部压缩成一次拨动开关。

核心痛点 —— 你是否也遇到过？

  • 想在手机上给客户/朋友演示一个静态站点，被逼装 Termux + 敲命令行
  • 现有「本地服务器」App 都是 shell 环境包装 —— 安装重、操作绕
  • 只能同时跑一个站点，端口、目录来回切换
  • 飞行模式 / 无网络环境，浏览器联网预检直接拒绝打开 127.0.0.1
  • 重装应用后站点全丢，备份迁移全靠手动拷文件

解决方案 —— 一个 APK 全搞定

  • 一个原生 APK：选一个 ZIP，拨一个开关，站点跑在 http://127.0.0.1:<端口>
  • 纯原生 Jetpack Compose 应用，零运行时依赖，服务器 / ZIP 引擎 / 下载器全部手写
  • 多站点并行：每个站点是独立端口上的隔离服务器实例，想跑几个跑几个
  • 回环接口永不掉线，应用内预览直连服务器，飞行模式照常访问
  • 存储位置可迁移：复制 → 字节校验 → 原子替换，失败自动回滚

Features

功能特性

三大模块、九项能力，覆盖从部署到安全的所有细节。

🚀 服务器与站点管理

  • 一键启停

    前台服务保活站点；呼吸状态灯一眼看清运行状态。

  • 站点库

    字母头像卡片，实时端口/状态/快捷操作：应用内预览 · 系统浏览器 · 复制链接。

  • 独立端口

    每站点 8000–9999 随机分配，查重 + 设备占用探测，详情页可改。

📦 部署与内容

  • 多样部署

    本地 ZIP 导入或 URL 在线拉取（带下载进度）；内置图文打包指南。

  • 内容热更新

    「更新包」原地覆盖内容，端口与设置原样保留。

  • 随应用启动

    标记站点后，每次打开 App 自动拉起对应服务器。

🛡 安全与可靠

  • 加固的服务器

    纯 Kotlin 手写 HTTP/1.1：SPA fallback、HTTP Range 流式（视频拖动）、路径穿越防护、30+ 类型 MIME。

  • 存储迁移可回滚

    复制 → 字节校验 → 原子替换，失败自动回滚。

  • 安全外跳

    外部链接跳转前确认（可在设置中关闭）。

FAQ

常见问题

断网后浏览器打不开 127.0.0.1？

服务器没问题 —— 回环接口永不掉线。很多厂商浏览器（OPPO、vivo、小米、华为…）会做联网预检，在请求到达 127.0.0.1 之前就弹出「无网络」页。改用应用内 🌐 预览即可，它直连服务器，无预检。

端口会冲突吗？

不会。每站点在 8000–9999 内随机分配，分配时查重其他站点并探测设备占用；详情页可改（需先停止站点）。

站点存在哪里？

默认应用私有存储（升级不丢，卸载会清）。设置 → 站点根目录可切换到用户目录（需「所有文件访问」权限），迁移自动完成且可回滚。
